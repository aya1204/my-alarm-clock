# my-alarm-clock

## アプリケーション名
時計（iPhone風Webアプリ）

## プロジェクトの概要
iPhone標準の時計アプリ（アラーム機能）のUI／UXを再現したWebアプリケーションです。

- 主な機能：
    - **アラーム機能**： ON/OFF切り替え、新規追加・編集・削除、繰り返し（曜日指定）設定
    - **睡眠｜起床スケジュール**： 就寝/起床時刻の設定、睡眠時間の自動計算、専用アラーム設定
    - **iOS風UI/UX操作**：
        - 3Dドラムロールピッカー（スヌーズ継続時間のドラッグ/ホイール操作）
        - サウンド試聴および音量調整スライダー
        - 触覚（バイブレーション）設定画面の見た目を再現

## ローカルでの実行方法
1. リポジトリをクローン
    git clone git@github.com:aya1204/my-alarm-clock.git

2. クローンしたディレクトリに移動する
    cd my-alarm-clock

3. `index.html`をブラウザで開く（ドラッグ、またはターミナルから実行）
    # macOSの場合
    open index.html
