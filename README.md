# my-alarm-clock

## アプリケーション名
時計（iPhone風Webアプリ）

## プロジェクトの概要
iPhone標準の時計アプリ（アラーム機能）のUI／UXを再現したWebアプリケーションです。
JavaScriptを用いて動的な画面制御と時刻判定を行い、アラームの設定・編集・削除および音の再生機能を実装しています。

- 主な機能：
    - アラームのON/OFF切り替え
    - アラームの新規追加・編集・削除
    - 時刻・サウンド・スヌーズ継続時間の設定
    - ラベル入力（空欄時は「アラーム」と表示）
    - スヌーズ機能のON/OFFおよび時間選択（ドラッグ/ホイール操作）
    - 指定時刻における音声再生

## ローカルでの実行方法
1. リポジトリをクローン
    git clone git@github.com:aya1204/my-alarm-clock.git

2. クローンしたディレクトリに移動する
    cd my-alarm-clock

3. `index.html`をブラウザで開く（ドラッグ、またはターミナルから実行）
    # macOSの場合
    open index.html
